# MAJI_NDOGO
data analytics project
Maji Ndogo – Water Source Development & Budget Tracking

📌 Project Overview
Maji Ndogo is a Power BI dashboard designed to track the development and budgeting of water sources across different provinces. It provides insights into water infrastructure, financial allocations, and the status of various water sources, helping decision-makers ensure sustainable water management.

🔍 Key Features
Water Source Tracking: Monitor different water sources and their operational status.
Budget Analysis: Analyze the allocation and expenditure of funds for water development.
Geospatial Visualization: Uses JSON-based maps to display water source locations across provinces.
Replacement Monitoring: Identifies water sources that require replacement or maintenance.
🗂️ Data Sources
CSV files containing water source details, budgets, and development progress.
JSON files for geospatial mapping of water source locations.
📊 Technologies Used
Power BI – For data visualization and interactive dashboards.
JSON Mapping – To create custom geographic maps.
🚀 How to Run the File
Ensure Power BI Desktop is Installed

Download and install Power BI Desktop from Microsoft’s official site.
Open the Dashboard

Locate the Maji Ndogo Power BI file (Maji_Ndogo.pbix).
Double-click to open it in Power BI Desktop.
Load Data

If prompted, ensure the CSV and JSON files are in the correct folder.
If necessary, update file paths in Power Query to match your local directory.
Explore the Dashboard

Navigate through different pages to explore budget allocations, water source status, and maps.
Use filters to drill down into specific provinces or water sources.
